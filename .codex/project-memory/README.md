## 证据优先级

从高到低：

1. 当前代码、Git 状态和当前配置；
2. 本轮运行测试、浏览器证据、API 响应和日志；
3. 可复现的历史测试输出和 Git 提交；
4. 正式专题文档；
5. `.claude/`、交接报告、旧分析和会话摘要。

后一级不能覆盖前一级。`healthy`、编译成功、日志存在、构建完成或历史“已验证”都不能自动升级为当前业务可用。
