## Edge 复验顺序（用户操作）

1. **身份与基础导航**：打开预览的 `/build-info.json`，核对 `v1.6.0+dingxin.1` 和暂存树标识；新测试账号登录。依次进入首页、创作、项目、素材、任务、自由画布，刷新/前进/后退各一次。检查空态、加载失败后的可恢复性；登录态网络请求不应进入生产端口 3000。
2. **自由/项目画布**：新建测试画布及项目画布，分别在浅色/深色点网格间切换；打开左侧栏、缩放与适应视图、素材按钮、顶部工具、底部主工具与画布外观。将 Edge DevTools 停靠右侧并收窄可视宽度，再折叠/展开侧栏，确认控件可见且不重叠、无横向误滚、节点仍可拖拽和编辑。刷新后确认主题和画布内容持久化；观察控制台与 Network 失败请求，特别分开记录本机 Runtime `127.0.0.1:17371` 不可用和后端报价 400，不能只报错误总数。
3. **创作/分镜/导演台**：进入 `/create`，仅查看生成类型、模型与规格，不提交付费生成；新建测试项目，打开分镜制作，修改并保存文本草稿、刷新确认。导演台从项目内可见入口进入，检查加载、保存/返回/再次打开；F6“保存失败后选择留在导演台”仅在专用可控失败夹具可复现时才判定，通过正常保存不能冒充 F6 通过。检查 DevTools 报价调用的请求条件与响应正文（先遮掉身份和敏感数据）。
4. **上游 v1.6.0 新增交互**：检查 Agent 面板开关、Live2D/占位回退、停止与续接 UI；音频/角色资产入口、模型选择与按秒报价展示；素材引用与回收站删除提示。只验证无费用的界面/草稿/配置路径，素材物理删除请用新建测试素材，勿删除已有数据。Pi Agent 真实多轮、音频/视频/图像生成、Comfy Bridge 设备与计费均需单独授权与环境。
5. **故障和权限**：断开预览后端仅在隔离环境、可控且不损坏数据时测试“本地缓存成功≠服务端保存”；恢复后检查任务/资源加载、跨测试账号数据隔离、管理员页面的目录与价格只读展示。不为消除控制台报错而放宽私网 SSRF、把密钥放浏览器或临时启用付费渠道。

用户反馈建议逐项提供：预览版本标识、Edge 地址/窗口宽度与缩放、操作步骤、预期与实际、控制台首条相关错误、Network 请求 method/path/status/脱敏响应、截图。记录 `通过 / 失败 / 未测 / 不适用`，不把没复现的失败场景写成通过。
