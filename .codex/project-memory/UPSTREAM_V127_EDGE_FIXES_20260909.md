2. `601e5ada`：系统渠道报价在请求前同时检查持久能力和精确价格档。真实数据库中Wan3.0只有图生视频、1图、720p、15秒价格档；30秒/1080p或未绑定图片的3秒分镜直接显示“当前模型尚未配置所选规格的价格”，不再向后端发送已知无效报价。
3. `0d815d15`：暗色固定主题点网格从`rgba(178,178,178,.18)`调整为`rgba(210,210,210,.30)`；线网格和自定义透明度合同不变。
