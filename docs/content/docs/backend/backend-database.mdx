# 后端数据库

## 渠道模型目录状态

`channel_models` 同时保存管理员配置和供应商目录元数据。目录拉取不会自动使模型可用，也不会自动配置价格。

| 字段 | 说明 |
| --- | --- |
| `support_status` | `ready`、`planned`、`unsupported` 或 `deprecated` |
| `support_reason` | 当前状态的可读原因 |
| `catalog_source` | `manual`、`upstream` 或官方目录来源 |
| `catalog_version` | 目录版本，便于审计和幂等更新 |
| `supported_operations_json` | 官方声明并经项目识别的操作列表 |
| `documentation_paths_json` | 生成该目录项的本地官方文档证据 |

只有 `ready` 模型能进入启用查询、定价/编辑、模型测试和逻辑模型线路。自动发现的新模型默认停用、未定价；`planned` 等状态只允许管理员查看。

升级旧数据时，只有同时具备能力类型、协议和有效 `capability_config_json` 的人工配置才会标记为 `ready/manual`；缺失持久能力配置的记录即使已有能力/协议也标记为 `planned/legacy`。补齐仅作用于停用、未定价且没有能力配置的记录，并使用更新时间条件避免覆盖并发管理员保存。

公开目录和任务准入共用同一份持久能力配置；配置缺失、损坏或不完整时模型会 fail closed，不再由目录单独补造协议默认值。价格同样要求 `price_configured=true`：仅残留正数价格但仍标记为未配置的模型或价格档不会进入公开目录和任务路由。
