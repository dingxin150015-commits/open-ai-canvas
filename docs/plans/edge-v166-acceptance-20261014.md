# v1.6.6 本地集成候选：Edge 验收指导

本文件只适用于历史隔离预览 `localhost:3001`；2026-10-15 的生产环境 `localhost:3000` 请使用 [生产 Edge 手工复验](edge-v166-production-20261015.md)。3001 不含本次 AutoDL 音频合包，不可用于判定最终生产插件状态。

更新：2026-10-14 23:30 CST。最终自动化与迁移证据已通过，下面的浏览器交互尚未由用户确认；不得把 HTTP 200 或源码测试当成人工验收。

## 环境与边界

- 仅使用用户已登录的 Microsoft Edge，打开 **http://localhost:3001**。3000 是旧生产服务，不要在 3000 执行故障注入。
- 预览使用生产快照的独立副本，编辑不会写回生产。浏览器缓存按端口隔离，因此预览不会复用 3000 的 IndexedDB；旧缓存连续性还需要晋升后的只读复核。
- 候选后端所在 Docker 网络为 internal，无默认外网路由；Web 单独发布本机端口。不要点击任何真实模型生成、Agent 执行或支付命令，不要把无法访问第三方媒体/模型误判为已验证的供应商结果。
- 不清除浏览器站点数据，不删除旧项目/素材，不测试真实扣费。新建测试项目和节点即可。

## 1. 身份与基本路由

1. 查看 `/build-info.json`：`version=v1.6.6+dingxin.1`，`commit=candidate-cbf3ebd38153`。这是候选树标识，不是正式发布提交。
2. 查看 `/api/health/ready`：前后端构建标识一致，Schema `51/51`、`ready=true`、`activeWorkerTasks=0`。
3. 进入首页、创作、项目概览/章节/分镜/画布/资产、自由画布及灵感页。分别直接打开和刷新 `/create`、`/canvas`、`/inspirations`、`/inspirations/`。
4. 如果需要重新登录，只在预览使用既有账号；不要修改生产密码、模型密钥或价格。

## 2. 画布布局与主题

1. 项目画布与自由画布分别测试：打开/关闭侧栏，再将 DevTools 停靠右侧/底部并拖窄页面。
2. 检查顶栏不重叠，缩放/适应视图/素材/主工具栏可达，省略号里的命令未丢失；素材图标与数字应独立清晰。
3. 切换浅色、深色及自定义；点/线/空白网格分别检查。深色点网格应可见，不出现过强或重复透明度。
4. 在画布更改外观后返回首页，确认工作区主题偏好没有被画布临时主题覆盖。
5. 创建文本节点，单击铅笔改名；拖拽、连线、缩放、撤销/重做、弹窗与滚轮边界分别检查。上传一张本地测试图片，确认比例和素材入口正常。

### 可选 F6：只在预览注入本地保存失败

断网未必导致 F6：预演保存首先依赖 IndexedDB，不能用 Offline 就宣称已覆盖本地存储失败。下面是用户手工可选的临时注入，代理本轮没有执行；不舒服使用 Console 时跳过并标 `test_only_pending`。

1. 在预览中新建一个测试画布/预演场景，先确认正常保存。
2. 预演打开时在 Console 运行下列代码；它拒绝在非 `localhost:3001` 环境执行，仅让画布目录写入抛出异常，不删除任何数据：

```js
(() => {
  if (location.origin !== "http://localhost:3001") throw new Error("仅允许隔离预览");
  if (globalThis.__v166PrevisRestore) throw new Error("故障已注入，请先恢复");
  const original = IDBObjectStore.prototype.put;
  IDBObjectStore.prototype.put = function (value, key) {
    if (this.name === "app_state" && typeof key === "string" && key.startsWith("infinite-canvas:canvas_store:user:")) {
      throw new DOMException("F6 preview-only injected write failure", "QuotaExceededError");
    }
    return original.apply(this, arguments);
  };
  globalThis.__v166PrevisRestore = () => {
    IDBObjectStore.prototype.put = original;
    delete globalThis.__v166PrevisRestore;
  };
  return "已注入，仅影响本标签页的预览画布写入";
})();
```

3. 移动演员使场景有新修改，再关闭预演台。预期提示“保存未完成”，选择 **留在预演台** 后草稿仍在；不要选“放弃修改并关闭”。
4. 运行 `globalThis.__v166PrevisRestore?.()` 恢复，再重试保存/关闭并重新打开，确认修改保留。刷新标签页也会恢复原型，但请先保存草稿。
5. 如注入没触发、没有目标存储驱动或出现其他提示，记录截图和操作；不扩大注入范围，不在生产复现。

## 4. 本地功能与控制台

- 模型配置页面：七个关键 Gemini/DashScope/OpenAI 插件仍启用，百炼精确模型、时长/分辨率/参考图与单请求多图选项仍可发现。只查看或在测试草稿切换，不修改实际渠道/价格/密钥。
- 人像筛选、资产标签编辑、Comfy Bridge 设备/工作流入口检查；预览禁止外联，真实设备执行与付费模型端到端均不计为通过。
- 创作、分镜和画布分别清空 Console 的显示记录后操作、刷新并等待一分钟；观察是否反复请求不可用 Runtime，是否出现未捕获异常或异常 400。
- 如果有错误，提供完整 Request URL（先去掉密钥）、状态、请求参数结构、响应 errorCode/requestId、Console 调用栈。第三方惰性加载提示是浏览器警告，不等同于应用错误。
- 两个标签页打开新测试画布：不同字段编辑应按协议保留；同字段冲突应可见，不能悄悄覆盖。测试网络断开/恢复后的 pending/error 状态和未确认操作重放，最后恢复 Online。
